Control y privacidad

La cámara intenta leer el código PDF417 del DNI. El sistema verifica la edad y bloquea un segundo canje registrado en este navegador. Se guarda un identificador derivado del número de documento con una clave local, no la foto ni los datos del código. Los registros permanecen en este celular hasta que se borren los datos del navegador. No usar modo incógnito.

La persona encargada debe verificar visualmente que el DNI pertenece al cliente. La lectura de un código no demuestra autenticidad del documento.

Solo mayores de 18 años. No se entrega alcohol a menores. Esta versión funciona en un único celular y requiere HTTPS para acceder a la cámara. Si se borran los datos del navegador, se pierde el control de duplicados. No reemplaza la verificación presencial.
